# Aufmaß-Protokoll als Web-App

Dateien: index.html, manifest.webmanifest, icon.svg, sw.js. Alle vier gemeinsam in denselben Ordner
auf einem Webspace mit HTTPS hochladen. Der Link zeigt dann auf index.html bzw. den Ordner.

## GitHub Pages
1. Auf github.com ein neues Repository anlegen (z. B. aufmass), Public.
2. Die vier Dateien per "Add file > Upload files" hochladen und "Commit changes" klicken.
3. Settings > Pages > Source "Deploy from a branch", Branch "main", Ordner "/ (root)", Save.
4. Nach etwa einer Minute ist die App unter https://<benutzername>.github.io/aufmass/ erreichbar.

## Aufs Handy
Link in Chrome öffnen, Menü (drei Punkte) > "Zum Startbildschirm hinzufügen" bzw. "App installieren".

## Update
Neue index.html (und ggf. weitere Dateien) hochladen. Beim nächsten Öffnen mit Internet gilt sie sofort.
